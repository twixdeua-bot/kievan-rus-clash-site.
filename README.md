# КИЕВСКАЯ РУСЬ — Clash Royale

Обновление включает весь текущий сайт и отдельный раздел «Бесплатные награды».

## Раздел наград
- Добавлена вкладка 🎁 «Награды».
- Netlify Function `/api/rewards` сначала пробует публичную страницу Clash Loot. При отказе (например, HTTP 403) пробует публичный поиск Reddit в r/SupercellFreebies и показывает подходящие публикации сообщества.
- Результат кэшируется на 15 минут; в интерфейсе есть ручное обновление и ссылка на источник.
- Если Clash Loot блокирует Netlify, резервный источник — публичные публикации Reddit. Резервные результаты являются постами сообщества, а не гарантированно действующими наградами; нужно проверить публикацию и срок действия ссылки. Если недоступны оба источника, интерфейс покажет ошибку, а остальной сайт продолжит работать.
- Это чтение публичной страницы, а не официальный API; полного охвата всех раздач и безошибочной актуальности гарантировать нельзя. Награды и ссылки могут истекать независимо от обновления сайта.

## Остальные функции сохранены
- Клан `#LC82C82C`, статистика и речные гонки через `/api/clan`.
- Две основные вкладки клана и вложенные вкладки сводки/речных гонок.

## Развёртывание
Загрузи содержимое ZIP в Netlify как обычно. Существующая переменная окружения `CLASH_ROYALE_API_KEY` для функции клана не включена в архив и должна остаться в настройках Netlify. Для наград отдельный ключ не нужен.


## Вкладка «Бесплатные награды» (RoyaleAPI)
Функция `/api/rewards` сначала обращается к странице бесплатных наград RoyaleAPI, затем пробует RoyaleTracker и Clash Loot. Отдельный GitHub или API-ключ для наград не требуется. Обновление запускается при открытии вкладки и кнопкой «Обновить список»; Netlify кэширует успешный ответ на 15 минут.

Важно: сбор зависит от доступности и HTML-разметки сторонних сайтов. Если все источники блокируют серверные запросы или меняют разметку, функция покажет ошибку вместо выдуманных наград. После загрузки ZIP нужно заново развернуть сайт на Netlify.
